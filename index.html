§0 · AVISO PRELIMINAR Y ÁMBITO DE APLICACIÓN

El presente registro se rige por el principio de enumeración exhaustiva no exclusiva de recursos hipertextuales (en adelante, «RH») alojados en el repositorio de origen, entendiéndose por tal el conjunto C = {x ∈ R | ext(x) ∈ {.html, .htm}} descontadas las exclusiones de §CFG. Toda cifra aquí consignada es de carácter indicativo, derivada por análisis léxico elemental del flujo de bytes de cada RH, y no constituye garantía alguna de exactitud semántica [1][2]. La lectura de este documento no presupone conocimiento previo, aunque lo agradece.

§4 · GLOSARIO DE ABREVIATURAS, SÍMBOLOS Y CÓDIGOS DE ESTADO

ID₁₆
Huella FNV-1a (32 bits, hex) de la ruta canónica.
RMD
Código de directorio contenedor; «·» = raíz.
NOM
Nombre de archivo sin ruta.
TÍT
Contenido de <title>; en su defecto, NOM normalizado.
Ø(B)
Longitud en octetos del flujo.
PAL
Palabras tras eliminar marcado, <script> y <style>.
ETQ
Total de etiquetas de apertura, cierre y declaración.
SCR
Bloques <script>. 0 = documento estático.
GRF
Elementos <img>, <svg> y <canvas>.
ENL
Anclas <a>.
ENC
Encabezados h1–h6.
LÍN
Saltos de línea + 1.
CRC
Huella FNV-1a del contenido completo (verifica cambios).
AVN
Posición máxima de desplazamiento, 0–100 %.
EST
N = nulo (0 %) · P = parcial (1–94 %) · C = completo (≥95 %).
MRC
Marca de favorito (★ / ☆), alternable.
…
Magnitud pendiente de cómputo.

§5 · ÓRDENES DE TECLADO (ÁMBITO GLOBAL)

[ / ] → foco en Φ · [ Esc ] → RET (retorno al registro) · [ ← ] ANT · [ → ] SIG · [ f ] alterna MRC del RH en lectura. En lectura, el desplazamiento se registra con latencia de 250 ms y persiste en el almacenamiento local del agente de usuario [3].

§6 · NOTAS AL PIE Y SALVEDADES

  1. La enumeración se obtiene de books.json, si existe; de lo contrario, de la API pública de árboles Git (límite: 60 consultas/h por origen, caché 10 min).
  2. Las magnitudes léxicas (PAL, ETQ…) proceden de expresiones regulares y pueden diferir de un análisis sintáctico completo.
  3. Los estados (AVN, EST, MRC, τ) son locales a este agente de usuario; no se sincronizan entre dispositivos.
  4. Cualquier discrepancia entre ID₁₆ y CRC tras una edición del RH es esperable y no constituye error.
  5. Parámetros opcionales de despliegue: véase el objeto CONFIG.
